\## Objetivo

Aprender a crear un repositorio local, conectarlo con GitHub y sincronizar cambios utilizando Git.



\## Descripción

En esta práctica se creó un repositorio local, se realizaron commits, se vinculó con GitHub y se sincronizaron cambios entre el repositorio local y remoto.



\## Comandos utilizados



\- git init

\- git status

\- git add .

\- git commit

\- git remote add origin

\- git push

\- git pull



\## Conclusión



Aprendí a utilizar Git para controlar versiones y GitHub para almacenar y sincronizar proyectos.
